# 星垂 · 潮汐来信

适用于 SillyTavern 手机界面。打开酒馆的「扩展 → 安装扩展」，粘贴下面的链接，安装后刷新。

```
https://github.com/Alina12901/tide-mobile-lite
```

- 续读卡片显示上次会话的角色和章节数。聊天页保留潮汐来信的角色标题栏和返回键，以当前角色卡面作为微清透背景。正文和输入框直接使用酒馆中的当前会话。
- 相册按每批 12 张加载缩略图，轻点翻开小传、世界书和预设，按「进入聊天」打开会话。
- 顶部的月亮和太阳切换日夜。聊天页左上角返回入口页，右上角打开角色资料与会话工具。在「主题与背景」中选择「恢复原版酒馆」可退出外壳。
- 自 1.3.11 起内置[用量记账](https://github.com/Alina12901/yongliang)。在人间清欢 → Token 用量查看记录和填写单价。已有账本和价格会沿用，同时启用独立版也只统计一次。按量按百万输入、输出 Token 计价，按次按请求计价。

手机布局适用于不超过 800 CSS 像素的窗口。角色缩略图、会话记录和背景都从自己的酒馆读取。

翻面动效和简介提取适配自 [star-flip](https://github.com/Alina12901/star-flip)。

1.2.0：人间清欢 → 世界书留在外壳内，可查找书和词条、修改名称/关键词/正文/启用状态。点保存才写回酒馆；同一本书内返回目录会保留未保存草稿，退出书本后清除。其他高级世界书功能仍可在恢复原版后使用。已安装旧版时，在扩展管理中更新后刷新即可。

### 1.3.0 · 会话与工具内页

首页可进入 API、预设和世界书。书内的「本书完整编辑」沿用酒馆编辑器，在同一风格的内页中打开。预设、连接设置与用量为全局设置。

从聊天点 ▤ 可看当前角色、群成员和会话关联的世界书，点左上角返回原聊天。相册卡背上的书名也可以直接点开，再返回原卡。工具内页按需加载。

### 署名与版本溯源

潮汐来信由星垂发布，官方仓库为 `Alina12901/tide-mobile-lite`。分享副本时请保留作者署名、来源和原有组件署名，修改版请注明改动。

在手机酒馆的「扩展程序 → 潮汐来信」可以查看版本溯源码。每个发行版本的所有安装者共用同一个码。核对转发包时，请以官方仓库对应提交中的 `provenance.json` 为准，逐文件核对其中的 SHA-256 指纹。文本统一为 LF 换行后计算，图片使用原始字节。发布者可以运行 `python tools/provenance.py` 重新生成记录。
